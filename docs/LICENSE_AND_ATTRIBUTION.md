# Licensing and attribution
This template package grants no rights to later-downloaded source materials.
Inspect each source's own license, copyright, third-party credits, and redistribution
terms. Record them in source_register.csv. Keep notices intact. If redistribution
is not permitted, share source URL and metadata rather than the file itself.
NASA media guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/
